SQL Server Integration Tutorial

SQL Service Integration Service Data Transformation Package built using Visual Studio 2022 and deployed to a SQL Server 2022 Database.

Data Transformation SSIS Package using Financial Transactions SQL Server Database, Exchange Rates Excel, and Supplier CSV File for data sources which then performs a number of SQL Execute Tasks
and Data Flow Tasks to first load and then transform and combine the data from these data sources into a final result set which is finally loaded into a destination Financial Transactions Warehouse SQL Server Database.
